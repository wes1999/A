# Pop 110 Digital V2

Aplicativo Android experimental de velocímetro para Galaxy S24. Combina velocidade GNSS e acelerômetro usando um filtro, exibe gráfico dos últimos 60 segundos, oferece calibração e grava telemetria em CSV localmente. **Não substitui o velocímetro original.**

O APK de teste será disponibilizado nos artefatos do GitHub Actions quando a compilação terminar. O código-fonte é publicado aqui durante a compilação automatizada.

Atenção: este repositório é **público**, conforme a configuração atual da conta do proprietário. Não inclua registros de trajetos pessoais, tokens ou outros dados privados.
